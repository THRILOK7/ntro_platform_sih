                              PREREQUISITES

Required:

  • Tesseract OCR (for image/PDF OCR functionality)

================================================================================
                          BACKEND SETUP (5 MIN)
================================================================================

1. Navigate to backend directory:
   cd backend

2. Create and activate virtual environment:
   python -m venv venv
   .\venv\Scripts\activate

3. Install dependencies:
   pip install -r requirements.txt

4. Verify .env has OpenAI API key:
   cat .env

5. Start backend server:
   python main.py

   Expected: "Uvicorn running on http://0.0.0.0:8000"

6. Test health endpoint:
   curl http://localhost:8000/health

   Expected response:
   {"status": "operational", "phase": "Phase 1: Ingestion Engine"}

================================================================================
                        FRONTEND SETUP (3 MIN)
================================================================================

1. Navigate to frontend directory:
   cd frontend

2. Install dependencies:
   npm install

3. Start development server:
   npm run dev

   Expected: "Local: http://localhost:5173/"

4. Open browser:
   http://localhost:5173

   You should see:
   • NTRO Platform header
   • "Operational" status badge
   • Drag-and-drop file zone
   • Parameter controls
   • "Process & Ingest Pipeline" button

================================================================================
                            TROUBLESHOOTING
================================================================================

Backend won't start:
  • Check Python 3.10+: python --version
  • Check venv activated: .\venv\Scripts\activate
  • Check port 8000 free: netstat -ano | findstr :8000
  • Check OPENAI_API_KEY in .env

Frontend won't load:
  • Check Node 18+: node --version
  • Check backend running: curl http://localhost:8000/health
  • Clear browser cache: Ctrl+Shift+Delete
  • Delete node_modules: rm -r node_modules && npm install

File upload fails:
  • Check file size < 500 MB
  • Check OPENAI_API_KEY is valid
  • Check backend logs for error details

================================================================================
                          API QUICK REFERENCE
================================================================================

Health Check:
  GET http://localhost:8000/health

Ingest Raw Text:
  POST http://localhost:8000/api/v1/ingest
  Form fields:
    - raw_text: "Your text here"
    - parameters: {"target_audience":"General Public","tone":"Formal",...}

Ingest File:
  POST http://localhost:8000/api/v1/ingest
  Form fields:
    - file: (binary file upload)
    - parameters: {"target_audience":"General Public",...}

Supported file types:
  • PDF (.pdf)
  • Word (.docx)
  • Images (.png, .jpg, .jpeg, .gif, .bmp, .webp, .tiff)
  • Audio (.mp3, .wav, .m4a, .flac, .ogg)
  • Video (.mp4, .webm, .mov, .avi)
